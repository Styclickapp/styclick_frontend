## 20. Authentication Token Persistence, OTP Auto-Login, & Navigation Safeguards
- **Problem Diagnosed**:
  1. The backend `auth/verify` endpoint verifies OTP accounts successfully (HTTP 201) but does not return a session JWT token in its payload (`{"email": "...", "firstname": "...", "lastname": "..."}`).
  2. `verify_user.dart` previously navigated unconditionally to `Nav()` upon verification success even when no token was present. This dumped newly registered users into an unauthenticated app state where `ApiService._authHeaders()` found `Token read: EMPTY` and all authenticated calls (`user/profile`) failed with 401 Unauthorized.
  3. In `login.dart`, navigation to `Nav()` was situated outside the token validation block, allowing navigation even when the token was empty, and `prefs.clear()` wiped session state prematurely.
  4. In `api_service.dart`, HTTP 200/201 responses containing `{"status": false, ...}` were incorrectly treated as successful.
  5. In `splash.dart`, returning users were routed to `Nav()` purely based on `home == true` without verifying the token was actually present, trapping users in an invalid session loop.
- **Resolution Applied**:
  - `lib/core/services/api_service.dart`: Added fallback token retrieval synchronizing `SharedPreferences` and `nb_utils`. Added explicit checking for `{status: false}` in responses to prevent marking failed requests as successes.
  - `lib/modules/auth/register.dart`: Passed registration password to `VerifyUser(email, phone, password)` so the user can be automatically authenticated upon OTP verification.
  - `lib/modules/auth/verify_user.dart`: Added `password` parameter. Upon successful OTP verification, automatically calls `AuthService.instance.login()` to acquire a valid JWT, saves session data to preferences, and securely routes to `Nav()`. If password is not provided or auto-login fails, safely routes to `LoginScreen` instead of `Nav()`.
  - `lib/modules/auth/login.dart`: Added comprehensive token key extraction (`data['token']`, `data['data']['token']`, `data['access_token']`, etc.). Strictly gated dashboard navigation to only occur when `token.isNotEmpty`.
  - `lib/modules/splash.dart`: Added validation that `access_token` is present along with `home == true`; otherwise clears stale flags and redirects to `LoginScreen()`.
  - `lib/modules/settings.dart`: Updated "Log Out" button to clean up `access_token` from both `SharedPreferences` and `nb_utils`.
